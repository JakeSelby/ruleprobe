# Support

Start with the [README](README.md): the sixty-second run, writing a detector, and what the
numbers do and do not mean. `ruleprobe detectors` says what would run and why a gated detector
is waiting.

Everything below needs a GitHub account and is public.

- **Questions** ("how do I measure…", "why did this fire…") go to
  [Discussions, Q&A](../../discussions/categories/q-a).
- **Bugs** go in a [Bug issue](../../issues/new?template=01-bug.yml) with the command you ran and
  `ruleprobe --version`.
- **A detector that fired wrongly or missed** goes in a
  [Detector miss issue](../../issues/new?template=02-detector-miss.yml).
- **Ideas** go in an [Idea issue](../../issues/new?template=03-idea.yml) or
  [Discussions, Ideas](../../discussions/categories/ideas).
- **Security** reports follow `SECURITY.md`, never a public issue.

There is no private support channel. Everything happens in the open so the next person can
find it.

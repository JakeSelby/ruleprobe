## Goal

Cut ruleprobe 0.2.0 with a contract that matches what agent-harness imports on the day it ships, so
the harness bumps its pin with no code change (agent-harness AD-13). It runs last in the release,
after every in-scope item in Epics 1 to 5, RP-D010, and story 4.3 if the maintainer confirms it.
Binds FR-30 Declared public API, FR-31 Versioning policy, and AD-9 The contract is versioned, once,
in 0.2.0.

## Acceptance criteria

1. **Given** agent-harness `main` on the release day, **when** its ruleprobe imports, call shapes and
   non-name dependencies are re-derived, **then** the contract test is updated in the same change and
   passes, and the harness commit read is recorded.
2. **Given** `CHANGELOG.md`, **when** the version section is cut, **then** it names the 0.2 break
   (story 1.9).
3. **Given** `scripts/release_preflight.py`, **when** run in a fresh clone, **then** it is clean, and
   the wheel is published by the release workflow.

## Tasks

  - [ ] List root imports, submodule imports, call shapes and `ruleprobe.__file__` use, as FR-30

## Dev notes

Files to touch: `tests/test_contract.py` (created by story 1.8), `CHANGELOG.md`, `README.md`,
`docs/releasing.md`, and the version. epics.md names `pyproject.toml` for the version, but
`pyproject.toml` reads it dynamically from `ruleprobe.__version__`, which is `"0.1.0"` in
`ruleprobe/__init__.py` today, so the bump lands there.

The contract test must cover every FR-30 name and call shape, including `fn(events, ctx)` reading
`ctx.bash`, `ctx.finals` and `Parsed.event`. AD-9's non-name dependencies also hold: `SECRET_PATTERNS`
stays a literal list in `ruleprobe/detectors/common.py`; the wheel is
`ruleprobe-<version>-py3-none-any.whl`, carries `corpus/`, and imports from a zip. AD-8's
`dependencies = []` must still hold.

Testing: full suite, corpus floor, preflight.

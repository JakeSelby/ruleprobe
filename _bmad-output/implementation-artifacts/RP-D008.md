# RP-D008 — decision(rules): the section split unit

## Context

FR-15 splits one rule file into many rules, so a `CLAUDE.md` with twelve rules is twelve entries in the
coverage block. The unit of that split is open as PRD §11 Q2: headings, list items, or both. It blocks
FR-15 and is needed for v0.2.0. AD-12 already fixes the id form for a section rule as the file path,
`#`, and a slug of its heading text, with an ordinal suffix for a repeated slug; that form assumes a
heading exists. FR-15 also fixes what counts as a rule inside a unit: at least one line of text outside
a fenced block, a table and a blockquote.

The question: which unit does the 0.2.0 reader split on, and if list items are chosen, how is a
list-item rule's id formed?

## Options

1. **Headings only.** For: the simpler split, and it matches how most rule files are written (addendum,
   Section-level binding); AD-12's id form works unchanged and survives edits above the section.
   Against: a section holding several one-line bullet rules is one rule, so one catalog match or none
   decides the whole section.
2. **List items only.** For: catches one-line rules directly. Against: the addendum cites the
   RuleReceipt author's parse as suggesting these are a minority of a file (ref 3, low confidence);
   list items have no heading text, so AD-12's id form does not apply and a new, edit-stable id is
   needed.
3. **Both.** For: the most rules per file. Against: carries option 2's id problem, and needs a rule for
   when a bullet is its own rule versus part of its section's rule.

## Decision

Decided 2026-09-23 by the maintainer: section binding splits on headings only for 0.2. It is the
simpler split, and AD-12's id form works unchanged and survives edits above the section.

## Consequences

- RP-S015 builds against AD-12 as written; no spine amendment beyond stating headings only.
- A section holding several one-line bullet rules is one rule, so one catalog match or none decides
  the whole section.
- Bullet-level rules wait for a later minor, which must name a list-item id form.

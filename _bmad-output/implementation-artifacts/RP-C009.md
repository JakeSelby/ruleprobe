## Goal

Keep the root `AGENTS.md` to what a session started in another folder needs: the title
paragraph, a short `## For other repositories` section, and the sections other files read.
Everything repository-internal moves, byte for byte, into `.claude/rules/working-here.md`,
path-scoped to `**/*`, so Claude Code loads it only in sessions working in this repository.

## Acceptance criteria

1. **Given** the root `AGENTS.md`, **when** it is read, **then** it holds the title paragraph,
   `## For other repositories`, `## Gate`, `## The package contract` and the one-file section,
   in that order.
2. **Given** the original `AGENTS.md`, **when** its non-blank lines are compared with the two
   new files, **then** each line appears in exactly one of them in its original order, and the
   only additions are the new section, the rule file's front matter and its heading.
3. **Given** the Gate block, **when** it runs, **then** every command exits 0.

## Tasks

## Goal

Enforce the package envelope by tests, not review, so no change can quietly add a dependency, a
network call or a write from `report`. NFR-1 and NFR-5 hold in 0.1.0 (`pyproject.toml` declares
`dependencies = []`), but the enforcing tests AD-8 plans do not exist yet. No dependencies.

## Acceptance criteria

1. **Given** `pyproject.toml`, **when** the suite runs, **then** it fails if `dependencies` is not
   empty.
2. **Given** every module in `ruleprobe/`, **when** scanned with `ast`, **then** none imports
   `socket`, `urllib`, `http`, `subprocess` or a model client.
3. **Given** `report` over the corpus sessions, **when** socket creation and any write-mode `open`
   raise, **then** `report` succeeds and prints its table.

## Tasks

- [x] Parse `pyproject.toml` and assert `dependencies` is empty, on the 3.9 floor without `tomllib` (AC: 1)
- [x] Walk `ruleprobe/` with `ast` for forbidden imports (AC: 2)
- [x] Patch socket creation and write-mode `open` to raise, then run `report` over the corpus (AC: 3)

## Dev agent record

Implemented in `tests/test_envelope.py` (new; the assumed name kept). Validated by the suite, on
the current interpreter and on the 3.9 floor.

- **AC 1.** A reader for the one key: comments outside quoted strings are stripped, then the
  `[project]` table's `dependencies` array is read, anything but quoted strings refused as
  unreadable. It also fails when `dynamic` in `[project]` lists `dependencies`, and cross-checks
  with `tomllib` where it exists. Each check has a positive and a near-miss case.
- **AC 2.** An `ast` walk over every `.py` under the source tree's `ruleprobe/` (asserted, so an
  installed copy is never the one scanned) for `import`, absolute `from … import`, and
  `__import__` / `import_module` calls, under any alias bound by `from importlib import`, with a
  literal name positionally or as `name=`. Model clients are a named list (`anthropic`, `openai`,
  `cohere`, `mistralai`, `litellm`, `ollama`, `groq`, `google.generativeai`, `google.genai`,
  `vertexai`, `transformers`, `llama_cpp`). Positive and near-miss sources prove the scan bites.
- **AC 3.** Write-mode `open`, `io.open`, `io.FileIO` and `os.open`; `os.mkdir`, `makedirs`,
  `rename`, `replace`, `remove`, `unlink` and `rmdir`; and `socket.socket`, `create_connection`,
  `socketpair`, `getaddrinfo` and `gethostbyname` all raise and are recorded, so an attempt
  `report` swallowed still fails the test. `report --no-config` over the shipped corpus prints
  its table with nothing on stderr; a second run with `HOME` and `XDG_CONFIG_HOME` on an empty
  directory, config discovery on, `--json` and `--validity` reads every corpus transcript with no
  read error. A self-test proves each refusal, in a temporary directory, and that reads pass.
- **Status.** AD-8's heading and NFR-1 in the PRD now say implemented under #37, unreleased,
  shipping in v0.2.0, each with a `.memlog.md` line.

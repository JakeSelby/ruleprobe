## Goal

Enforce the package envelope by tests, not review, so no change can quietly add a dependency, a
network call or a write from `report`. NFR-1 and NFR-5 hold in 0.1.0 (`pyproject.toml` declares
`dependencies = []`), but the enforcing tests AD-8 plans do not exist yet. No dependencies.

## Acceptance criteria

1. **Given** `pyproject.toml`, **when** the suite runs, **then** it fails if `dependencies` is not
   empty.
2. **Given** every module in `ruleprobe/`, **when** scanned with `ast`, **then** none imports
   `socket`, `urllib`, `http`, `subprocess` or a model client.
3. **Given** `report` over the corpus sessions, **when** socket creation and any write-mode `open`
   raise, **then** `report` succeeds and prints its table.

## Tasks

- [x] Parse `pyproject.toml` and assert `dependencies` is empty, on the 3.9 floor without `tomllib` (AC: 1)
- [x] Walk `ruleprobe/` with `ast` for forbidden imports (AC: 2)
- [x] Patch socket creation and write-mode `open` to raise, then run `report` over the corpus (AC: 3)

## Dev agent record

Implemented in `tests/test_envelope.py` (new; the assumed name kept). Validated by the suite, on
the current interpreter and on the 3.9 floor.

- **AC 1.** A reader for the one key: the `[project]` table's `dependencies` list, comments
  stripped, anything but quoted strings refused as unreadable. The test also asserts
  `dependencies` is not listed in `dynamic`, and cross-checks with `tomllib` where it exists. Two
  near-miss tests prove the reader sees a real dependency and ignores other tables.
- **AC 2.** An `ast` walk over every `.py` under `ruleprobe/` for `import`, absolute
  `from … import`, and `__import__` / `import_module` calls with a literal name. Model clients
  are a named list (`anthropic`, `openai`, `cohere`, `mistralai`, `litellm`, `ollama`, `groq`,
  `google.generativeai`, `google.genai`, `vertexai`, `transformers`, `llama_cpp`). A positive and
  a near-miss source prove the scan bites and passes relative imports and look-alike names.
- **AC 3.** `builtins.open`, `io.open` and `os.open` raise on a write mode or write flag;
  `socket.socket`, `socket.create_connection` and `socket.socketpair` raise. Each attempt is
  also recorded, so one that `report` swallowed still fails the test. `report --no-config` over
  the shipped corpus sessions exits 0 and prints its table; a second test proves the guard
  refuses each form and still allows a read.

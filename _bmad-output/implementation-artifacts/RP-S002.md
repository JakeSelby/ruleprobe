## Story

As the maintainer planning ruleprobe 0.2, I want a dated, cited map of the projects that now
measure rule compliance from coding-agent transcripts, so that the brief, PRD and spine claim only
what the field leaves open and name the alternatives honestly.

## Context and value

ruleprobe was carved out of agent-harness on the claim that nobody measured whether a written
rule changed agent behaviour. A scan on 2026-09-23 found that two projects now do, on Claude Code
transcripts. Every downstream artifact's positioning depends on getting this right, and a public
claim that the field disproves is the fastest way to lose a reader's trust.

## Acceptance criteria

1. **Given** the 2026-09-23 web digest, **when** it is processed with `bmad-deep-recon` in
   Process mode, **then** a `research.md` exists with the competitive pack's dimensions, an
   academic-literature secondary dimension, recommendations bound to the brief, PRD and spine,
   open questions and a staleness map.
2. **Given** the finished `research.md`, **when** `recon_kit.py citations` runs, **then** every
   inline marker resolves to an appendix row and no row is orphaned.
3. **Given** the load-bearing claims about the two direct neighbours, **when** verification runs
   at the `normal` level, **then** each is checked against its primary source.
4. **Given** the semantic citation check, **when** a cited source does not back its sentence,
   **then** the confidence is downgraded and the mismatch logged, with no finding rewritten.
5. **Given** the artifact is public, **when** it is read, **then** it holds no local path,
   private repository name or personal detail.

## Design

### Approach

Process mode, not Run: the field digest was already gathered by a web-research subagent with 19
searches, so the run filed it as an import, digested each source into its own file, spot-checked
the load-bearing claims with 8 page fetches and 3 searches, and synthesised `research.md` in the
competitive pack's order. The type is `competitive` because the decision is positioning against
named players; academic literature is a secondary dimension because the deterministic-versus-judge
question is the design choice under the positioning.

### Decisions and alternatives

- **Process an import, not a fresh Run.** A second fan-out would have repeated the same searches;
  the budget went to verifying the claims the recommendations rest on.
- **The research firewall held.** The run did not read ruleprobe's own code or README as evidence
  about the field. A consequence: recommendation 2 (ship a Codex reader) was written without
  knowing 0.1.0 already has one. It was corrected with a project note after synthesis rather than
  by rewriting the finding, and the correction is in the memlog.
- **No local copies of private notes.** The import lists sources by URL; the maintainer's private
  assessments shaped the questions and are not cited.

### Do not implement

- The product brief, PRD or spine; each is its own story under RP-E001.
- A user-voice pass on the neighbours' users, which is an open question in the artifact.

# RP-E003 — Epic 1: A contract a downstream tool can pin

## Goal

A tool built on ruleprobe, agent-harness first, pins 0.2 and knows what will not move under it. The
epic is done when detector entries and rows carry a schema version, the fold map persists with the
rows it applies to, a contract test holds the declared public API, the undecided rule (#19) has
landed, and the versioning policy is written in the README. This is the one planned break (PRD §6).

## Scope and requirement coverage

In scope:

- Schema version on detector entries: FR-27, touching FR-10 (story 1.4).
- Schema version on rows and `report_data` results: FR-28 (story 1.5).
- Persisted fold entries and the shipped-id rename test: FR-29 (story 1.6). The in-memory fold is
  implemented (0.1.0) and not reworked.
- The undecided rule for negation over a skipped command: FR-12 (touched), NFR-4 (story 1.7, #19).
- The declared public API and its contract test: FR-30 (story 1.8).
- The versioning policy and the named 0.2 break: FR-31 (story 1.9).
- The enforcing tests for the package envelope: NFR-1, NFR-5 (story 1.10).
- Three decisions that fix open PRD questions before code writes them: Q9 (1.1), Q8 (1.2), Q12 (1.3).

Out of scope: compliance per opportunity (Epic 2), section binding and the catalog (Epic 3), explain
and label (Epic 4), the third reader (Epic 5), and the release itself (Epic 6). The FR-30 list is
re-derived before the tag in Epic 6 (story 6.2), not here.

## Children

In delivery order:

1. RP-D001 (#29): decision, the schema version's type and the value 0.2.0 writes. Decided
   2026-09-23: an integer; 0.2.0 writes `2`; absent means 1.
2. RP-D002 (#30): decision, whether root `__all__` names outside FR-30 join the declared API.
   Decided 2026-09-23: they stay importable and undeclared; a name joins only with a contract test.
3. RP-D003 (#31): decision, whether a 0.x minor may break again after 0.2.0. Decided 2026-09-23:
   yes, with notice: a Breaking changelog heading naming the migration and the contract test updated
   in the same change.
4. RP-S007 (#32): `schema_version` on detector entries.
5. RP-S008 (#33): `schema_version` on rows and `report_data`.
6. RP-S009 (#34): persisted fold map and a shipped-id rename test.
7. RP-B001 (#19): `not` and `absent` fire on a Bash command the shell parse skipped.
8. RP-S010 (#35): declare the public API and hold it with a contract test.
9. RP-T001 (#36): state the versioning policy and name the 0.2 break.
10. RP-T002 (#37): fail on a new dependency, a network call or a write from `report`.

## Architecture slice

- AD-9 The contract is versioned, once, in 0.2.0: schema version, fold map, shipped ids,
  `ruleprobe/contract_data.py`, the declared API test and its non-name dependencies.
- AD-4 Detectors under-count rather than over-count: the undecided truth table (#19).
- AD-7 The declarative format is a closed YAML subset: `schema_version` widens the entry keys.
- AD-8 The package envelope: the dependency test and the no-write, no-network `report` test.
- AD-1 Dependency direction: `contract_data.py` takes its place in the graph in the change that adds it.
- AD-14 Shared registry state is never mutated after import.
- Inherited agent-harness AD-13 and AD-21: the harness vendors a pinned wheel imported from a zip.

Components: `ruleprobe/matchers.py`, `ruleprobe/rules.py`, `ruleprobe/report.py`,
`ruleprobe/registry.py`, `ruleprobe/validity.py`, `ruleprobe/cli.py`, the new
`ruleprobe/contract_data.py`, `README.md`, `CHANGELOG.md`, `scripts/release_preflight.py`.

## Sequencing

- The three decisions have no dependencies and run in parallel. RP-D001 gates RP-S007 and RP-S008.
- RP-S009, RP-B001 and RP-T002 depend on nothing and can run beside the decisions.
- RP-S010 depends on RP-D002, RP-S007, RP-S008 and RP-S009.
- RP-T001 depends on RP-D003 and RP-S010.
- RP-B001 lands before Epic 2's story 2.4, which reads undecided through the same combinators.
- Every later epic writes rows and entries under the RP-D001 value and extends the contract test in
  the same change.

## Exit criteria

1. Every child is closed with its acceptance criteria met.
2. The contract test module exercises every FR-30 bullet and fails on a removal or signature change.
3. `tests/test_equivalence.py` and `ruleprobe corpus --floor 0.9` pass.
4. The PRD's NFR-4 status and the spine's AD-4 and AD-9 status lines match what shipped.
5. `CHANGELOG.md` Unreleased names each part of the break.
6. The repository gate in `AGENTS.md` is green on the 3.9 floor.

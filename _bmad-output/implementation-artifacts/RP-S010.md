## Story

As a downstream tool author,
I want every name, call shape and non-name dependency the harness uses declared and tested,
so that a pinned 0.2 wheel cannot break me silently.

## Context and value

FR-30 declares the public API. In 0.1.0 the README's public API section says "The public API is six
names" (`README.md`, PRD Q13) while FR-30 counts eight, and agent-harness imports far more than
either: names from `ruleprobe.shell`, `ruleprobe.events`, `ruleprobe.registry`,
`ruleprobe.validity`, `ruleprobe.declarative` and `ruleprobe.detectors.common`, plus call shapes and
four non-name dependencies. Nothing tests any of it, so a refactor can break the harness silently
(PRD risk "Silent contract drift until 0.2.0"). Depends on RP-D002 (#30), RP-S007 (#32), RP-S008
(#33) and RP-S009 (#34).

## Acceptance criteria

1. **Given** the contract test module, **when** it runs, **then** it imports each FR-30 name at its
   declared path, including the eight 0.1.0 names and every harness import.
2. **Given** a detector function built as `fn(events, ctx)`, **when** `run(events, stances,
   registry=Registry([...]), strict=..., errors=...)` calls it, **then** it reads `ctx.bash` (each a
   `Parsed` with `.event`, `.command`, `.heredocs`) and `ctx.finals`, and returns `(turn,
   tool_use_id)` pairs.
3. **Given** `Detector` built positionally with five arguments and subclassed with `__slots__ = ()`,
   **when** the test reads `.id`, `.rule`, `.event`, `.fn` and `.gate` on it and on each
   `common.DETECTORS` item, **then** each is present.
4. **Given** `hit(event)`, `hit(event, tool_use_id=False)`, `git_calls(parsed, ("commit",))`,
   `MARKER_RE.match`, `declarative.load(path)`, `score_corpus(registry=, directory=)` and the `Score`
   attributes, **when** exercised, **then** each returns the declared shape.
5. **Given** `ruleprobe/detectors/common.py`, **when** it is parsed with `ast`, **then**
   `SECRET_PATTERNS` is a plain `ast.Assign` of a literal list.
6. **Given** the built wheel, **when** it is placed on `sys.path` as a zip, **then** the package
   imports and `run` works without installation, the file is named
   `ruleprobe-<version>-py3-none-any.whl`, and it carries `ruleprobe/corpus/`.
7. **Given** the README's public API section, **when** a test compares it with the contract list,
   **then** they match, and the "six names" count (PRD Q13) is gone. [ASSUMPTION: a test checks the
   README against the list rather than generating it]
8. **Given** any removal or signature change of a declared item, **when** the suite runs, **then** it
   fails. This holds only for what the test exercises, so AC 9 to 11 make it walk FR-30's whole list.
9. **Given** an event from each of the five kinds, **when** the test reads `kind`, `turn`, `id`,
   `name`, `input`, `text`, `final`, `tool_use_id` and `tool_name` through `.get`, **then** each is
   present on the kinds `ruleprobe/events.py` documents it for.
10. **Given** FR-30's remaining call shapes, **when** exercised, **then** each returns the declared
    shape: `gate` as `None` or a `(dimension, variants_or_None)` pair; `MARKER_RE.match(value)` group 1
    indexes `Parsed.heredocs`; `input_of`, `text_of`, `normalise`; `below_floor`, `scores_as_dict` and
    `validity_table` positional; `Score(detector_id)` with `.add`, `.scored`, `.precision`, `.recall`,
    `.detector`; `score_corpus` raising `CorpusError`; `ctx.events` beside `ctx.bash` and `ctx.finals`.
11. **Given** the wheel imported from a zip, **when** the test resolves
    `os.path.dirname(ruleprobe.__file__)`, **then** `corpus/` is found beside it. [ASSUMPTION: the
    test unpacks the corpus or points `RULEPROBE_CORPUS` at it, as AD-9 says a zip caller does, and
    asserts only that the path resolves and `corpus/labels.yaml` is in the archive under it]
12. **Given** FR-30's list, **when** the module is read, **then** every bullet maps to at least one
    named test, and a comment names the FR-30 bullet each test covers.

**Amendment, 2026-09-23 (maintainer decision, Jake):**

13. **Given** a predicate from `compile_matcher` that returns the undecided value, **when** a Python
    caller passes its result to `is_undecided(value)`, **then** it returns `True`, and it returns
    `False` for `True`, `False`, `None` and any other value. `is_undecided` lives beside the
    undecided value in `ruleprobe/matchers.py`, is exported from the package root, joins the
    declared API in the README, and has its contract test like every declared name.
14. **Given** the matchers module docstring, `compile_matcher`'s docstring and the README, **when**
    they tell a Python caller how to avoid over-counting an undecided predicate, **then** they name
    both routes: compose through the declarative `not`, `any` and `all`, or test the result with
    `is_undecided` before negating it.

## Design

### Approach

Per AD-9, one contract test module is the declared API list; the README renders from it (checked by
AC 7), and a name joins only with its test. The module covers every FR-30 name, call shape and
non-name dependency, plus any names RP-D002 marks declared. The zip-import check uses the built
wheel, run in CI beside the existing wheel job.

### Decisions and alternatives

- Which root `__all__` names are declared: RP-D002 (#30).
- The list is re-derived from agent-harness `main` before the tag in story 6.2, not here.
- **Amendment, 2026-09-23 (maintainer decision, Jake):** this story also adds and declares a public
  helper `is_undecided(value)`. Since #19, a predicate from `compile_matcher` can return a falsy
  undecided value, and a Python caller who negates a predicate itself reads it as false and can
  over-count. `is_undecided` lets such a caller tell undecided from false. It is an additive name,
  not a rename, so it does not conflict with "Do not implement". AC 13 and 14.

### Do not implement

- No renames or signature changes to make names tidier; this story freezes what exists.
- No release tooling (RP-T001).

### Completion notes

- `tests/test_contract.py` holds `DECLARED`, the module-to-names map, and one or more tests per
  declared item; each test carries a `# Covers:` comment naming the item in words. Shipped tests
  cite no planning IDs, so the comments name the item rather than the FR-30 bullet number (AC 12).
- The README's public API section moved under its own `## The public API` heading, so the test
  can find it; it lists `DECLARED` module by module, keeps the 0.1.0 call shapes, adds the
  harness call shapes and the four non-name promises, and drops the "six names" count (AC 7).
- Wheel checks (AC 6, 11): with `RULEPROBE_WHEEL` set they read that built wheel; unset, they
  pack the source tree with the `package-data` globs from `pyproject.toml`, so the zip import
  and corpus-in-archive checks run on every suite run with no skip. The probe runs in a
  subprocess under `-I -S` with the wheel first on `sys.path`, asserts `ruleprobe.__file__` is
  inside the zip, runs `run` and `score_corpus` with `RULEPROBE_CORPUS` pointed at the corpus
  unpacked from the archive. CI's `package` job runs the module against the built wheel.
- Amendment: `is_undecided(value)` in `ruleprobe/matchers.py`, exported from the root and in
  `matchers.__all__`; its contract test gets a real undecided value from a `compile_matcher`
  predicate over an untokenizable command. That call needs the private `matchers._Where` and
  `matchers._Env`, because `compile_matcher`'s `where` and `env` arguments are not declared.
- `Registry(renamed=)` exists on this branch but is not in the declared list; story 1.6 owns it.
  When 1.6 lands, anything it declares (the `renamed=` keyword, a public fold function) joins
  `DECLARED`, the README list and a test here in the same change, and the wheel probe can
  assert `ruleprobe.contract_data` imports from the zip.

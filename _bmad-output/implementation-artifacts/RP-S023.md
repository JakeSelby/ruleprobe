## Story

As a developer whose rules mention compaction, model switching, secrets or `find`,
I want those rules bound to the shipped detectors,
so that the defaults measure my own rules.

## Context and value

The 0.2 catalog holds seven shapes, and four of the six shipped default detectors have none:
`cache-hygiene/compact`, `cache-hygiene/model-switch`, `secrets/secret-in-write` and
`transcript-hygiene/unfiltered-find`. A rule about any of them is never bound, so the one
detector already measuring the observable never measures the rule. RP-SP004 found 9 of the
per-sentence prototype's 11 zoo misses were catalog phrasings, and moved the 0.70 recall bar from
the binder to Epic 8 as a whole; the zoo's four labels for these detectors were counted apart as
"no catalog entry binds yet". Story 8.3 (#141, RP-S022) shipped per-sentence binding in #142 under
variant S (an exception or permission anywhere in a section unbinds every rule in it), at 0.65.

## Acceptance criteria

1. **Given** a rule sentence in the shape of each of `compact`, `model-switch`,
   `secret-in-write` and `unfiltered-find`, **when** it binds, **then** it binds that detector,
   catalog-bound, and the shipped detector measures it.
2. **Given** a near-miss sentence for each (an exception, a condition, a permission, a mention, a
   narrowing, a neighbouring topic), **when** it binds, **then** it stays unbound.
3. **Given** `secret-in-write` outside the defaults (Epic 9), **when** its rule binds, **then** the
   coverage block says which detector it bound and that the detector is not a default.
   **Deferred to Epic 9** (see Decisions, 4).
4. **Given** the rules zoo with positives and near-misses for the four shapes, **when** `corpus`
   runs, **then** it shows zero false binds, recall of at least 0.65, and the recall floor keyed to
   the new zoo's sha256 at the recall measured.

## Design

### Approach

- Four entries appended to `catalog.ENTRIES`, after the seven, so every existing coverage line
  and catalog order is unchanged. Each `detector` restates the shipped one under its id: its
  `when` equals `common.yaml`'s twin, and `Bundle.registry` keeps the `DEFAULT` detector in place,
  as for `no-verify` and `whole-file-cat`. Each carries `examples:` with a near-miss beside each
  positive, scored against both the catalog twin and the shipped detector.
- Patterns, all anchored, each binding only a rule as wide as its detector's count (as narrowed
  at PR #148's review):
  - `compact`: never, do not or avoid (triggering) compaction, compact or compacting, optionally
    "the context, conversation or session (window)", or "start a fresh session rather than
    compacting"; then an optional mid-session or "in the middle of a session" scope. The typed
    `/compact` and any task scope bind nothing.
  - `model-switch`: never or do not switch, change or swap (the) model(s) together with a
    mid-session, conversation or chat scope, or stay or stick with one model for the whole session,
    conversation or chat. A bare "do not change the model" and any task scope bind nothing.
  - `secret-in-write`: never write, hardcode, paste, put, embed or inline a secret, credential,
    API or access key or token, or private key, in or into a file, disk, the repository, a commit,
    or source or version control; the destination is required.
  - `unfiltered-find`: filter or narrow every `find` (command, call, search), optionally by or with
    a name, type, depth, path, size or pattern; or never run an unfiltered, bare or unbounded
    `find`. `find(?![\w-])` refuses "find-and-replace".
- Every one must reach the end of its sentence, through the lookahead `(?=[.!?]*$)`, so a second
  clause or a trailing qualifier ("never compact more than once", "from the home directory")
  leaves the rule unmeasured.
- Zoo: 56 new items (`k`, `n`, `w`, `u`), 10 positives and 46 near-misses; no label RP-SP004 froze
  changed, and five of this story's own positives were relabelled null at #148's review (below). The `about` text now says which items came with this story. The floor is re-keyed.

### Decisions and alternatives

1. **End-anchored patterns for the three session and write shapes.** Their detectors count every
   compaction, every model change, every secret-shaped write, so a rule with a trailing qualifier
   the pattern cannot read would be measured against events it permits. Rejected: prefix-only
   patterns like the seven, which bound "Never compact more than once per session" to a detector
   counting the first compaction. `unfiltered-find` stays prefix-only because its positives carry
   how to filter ("by name or depth"), which never narrows the rule. Amended at #148's review:
   all four must reach the end of the sentence, and `unfiltered-find` names the filters it accepts,
   since "from the home directory" narrowed a prefix-only match.
2. **`secret-in-write` names destinations, and passwords are not an object.** "Never paste a secret
   into the chat" is not a write the detector sees, and no pattern in the detector finds a password.
   Rejected: any object after the verb, which binds both. Amended at #148's review: the
   destination is required and is a file, disk, the repository, a commit or source control;
   source code, config files and scripts are narrower than every file the detector reads.
3. **Timing words scope to task as well as session.** The frozen zoo labels "Never switch models in
   the middle of a task" and "Do not run /compact mid-task" positive; RP-SP004 froze those labels,
   so the patterns read them. "Stick with one model per task" stays unbound: a session spans tasks.
   **Reversed at #148's review:** a task-scoped rule would be measured against every compaction
   and model change in the session, so task scopes are gone; `d01` and `d02` keep their frozen
   labels and now count as misses.
6. **Compaction in general binds, the typed command does not** (#148's review). The detector counts
   automatic compactions as well as `/compact`, so "Never run /compact" would count compactions the
   rule never forbade; "Avoid triggering compaction" forbids them all and binds.
7. **No `/model` phrasing.** The review allowed the `/model` command as a sign of the agent's model;
   it is left out for the reason of decision 6: a model can change by fallback without `/model`.
4. **AC3 deferred to Epic 9.** The generic reading, "a catalog-bound detector not in the base
   registry's default set says so", is two lines in `Bundle.summary`, but five catalog-only
   detectors (`test-after-change`, `force-push-default`, `pip-install`,
   `non-conventional-subject`, `secret-file-add`) are already outside `DEFAULT`, so it would change
   every existing catalog-bound line. Whether those count as "not a default" is a product call on
   what the default set means, which Epic 9 story 9.5 makes when it defines the set by NFR-10.
   Until then `secret-in-write` is a default and the note would print nowhere.
5. **Catalog size.** FR-16 and the spine recorded "a small set of six to eight shapes" for 0.2; the
   catalog now holds eleven, as story 8.4 plans. The size test asserts eleven, and PRD FR-16, its
   open question 3 and spine AD-12 carry dated amendments, the 0.2 lines kept as written.

### Do not implement

- Wider phrasings for the seven 0.2 entries (a separate story).
- Any change to an existing zoo label, or a looser false-bind gate.
- A change to the binder, its exception or condition words, or `DEFAULT`.

## Review findings

PR #148's review, all resolved in the follow-up commit:

1. **`model-switch` bound data and ML models** ("Do not change the model; write a migration.",
   "Do not change the model, only the data."). Resolved: a switch or change binds only with a
   session, conversation or chat scope, or as "stay on one model for the whole session".
2. **`compact` bound rules about the typed command** ("Never run /compact.", "Don't use /compact.")
   while the detector also counts automatic compactions. Resolved: the command phrasings are gone
   (decision 6); `k02` relabelled null.
3. **Task scopes on `compact` and `model-switch`** made both count across the whole session, and
   "Do not run /compact mid-task; compact between tasks." bound with a second clause. Resolved:
   task scopes removed (decision 3, reversed), and every pattern must reach the sentence's end.
4. **`unfiltered-find` bound a location scope** ("Never run a bare find from the home directory.")
   **and "find-and-replace"**, since `\b` accepts a hyphen. Resolved: the end anchor with a closed
   list of filters, and `find(?![\w-])`; `u03` ("over the repository") relabelled null.
5. **`secret-in-write`'s optional destination** bound "Never paste secrets." and "Never paste tokens,
   even in DMs.". Resolved: a file, disk, repository, commit or source-control destination is
   required; `w01`, `w02`, `w03` relabelled null.
6. **Test gap:** 16 near-misses unbound only through binder words. Resolved: every input above is a
   zoo near-miss (`k12`–`k15`, `n11`–`n15`, `w13`, `w14`, `u11`, `u12`), the near-miss tests also
   assert the pattern itself refuses each, and a test checks the guard after each `find`. With the
   end anchor, the guard is redundant for behaviour, so that test reads the pattern as written.

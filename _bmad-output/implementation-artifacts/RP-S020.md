## Story

As a maintainer of a rule set,
I want a draft detector with `examples:` from a rule's prose,
so that I can review and commit it instead of writing it from nothing.

## Context and value

Proposed only (maintainer decision 2, 2026-09-23). Nothing here is built unless RP-D011 keeps it. A
detector today is written by hand, as a Python function or a declarative entry compiled by
`compile_detector` in `ruleprobe/matchers.py`. This command would draft the declarative entry; a
person still reviews and commits it, so the measurement stays deterministic and model-free.

## Acceptance criteria

1. **Given** the core install, **when** story 1.10's tests run, **then** no core module imports the
   drafting code or a model client, and `dependencies` is still empty.
2. **Given** the user names the command and supplies model access, **when** it runs, **then** it
   prints, or writes to a path the user names, one entry with `schema_version` and `examples:` that
   `compile_detector` accepts.
3. **Given** a run, **when** it finishes, **then** no registry, corpus or rule file changed.
4. **Given** `report`, `detectors` and `corpus`, **when** run with the command installed, **then**
   they make no model call.

## Design

### Approach

The command ships outside the core install and the core never imports it (AD-8). It emits data: one
declarative detector entry carrying `schema_version` (story 1.4, AD-9) and `examples:` (FR-24), to
stdout or a user-named path. It validates its output with `compile_detector` before emitting.
`[ASSUMPTION: a separate distribution in this repository, carried from epics.md; RP-D011 decides]`

### Decisions and alternatives

Packaging, optional extra or separate package, is RP-D011's call (PRD Q4). No other decision is
recorded in the corpus.

### Do not implement

- Binding rules at report time, scoring detectors, or counting a drafted detector before a person
  commits it (FR-34 non-goals).
- Any write to a registry, corpus or rule file.
- Any model call in `report`, `detectors` or `corpus`, or any import from the core.
- A judge (tracked under RP-E002) or compliance by position (PRD Q5).

## Context

PRD Q5 asks whether the report should also break compliance down by position in the session (research recommendation 4); it would extend FR-21. PRD §8 puts it Out for 0.2.0 while Q5 stays open, and the spine says it needs AD-11 first. The question must be confirmed before 0.2.0 scope freezes, so it neither slips in nor is dropped by default. It is sequenced before the release story (6.2).

## Options

1. **Confirm it stays out of 0.2.0.** For: matches §8; AD-11's counts land first and can be observed before a positional split. Against: the positional view waits for a later minor.
2. **Bring it into 0.2.0 by naming a story.** For: the research recommends it. Against: widens a release whose one user-facing advance is compliance per opportunity (maintainer decision 3), and no story, AD or FR text defines it yet.

## Decision

Open: the maintainer's confirmation of PRD Q5. The corpus places it Out in §8. [ASSUMPTION: it stays out, as §8 says]

## Goal

The same transcripts give the same bytes on ubuntu, macOS and Windows, and the readers say what they set aside.

## Scope and requirement coverage

In: the CI matrix (NFR-11), reader health counts (FR-45), the determinism test and seeded parse fuzzing (NFR-3). Out: timing on testers' volumes, which runs in Epic 13's beta.

## Children

Proposed, unfiled until the epic starts: 12.1 CI matrix, 12.2 reader health counts, 12.3 determinism test, 12.4 shell parse fuzzing (epics.md, Epic 12).

## Architecture slice

AD-8 (determinism), AD-5 (the shell parse), AD-10 and AD-2 (readers). `.github/workflows/`, `ruleprobe/readers/`, `tests/`.

## Sequencing

12.1 first; 12.3 after it; 12.2 and 12.4 in parallel.

## Exit criteria

CI is green on 3 operating systems on Python 3.9 and 3.x, and output is byte-identical under two hash seeds and reversed file order.

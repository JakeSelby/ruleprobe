## Goal

Declare the package licence as an SPDX expression. `python -m build` warns that the table form of
the licence metadata is deprecated; setuptools says that form stops being supported after
2027-02-18. The issue records that this was found while setting up the release workflow. After
this chore the build runs clean of those warnings and the wheel carries an SPDX licence expression.

## Acceptance criteria

1. **Given** `pyproject.toml`, **when** it is read, **then** it declares `license = "MIT"` and
   `license-files = ["LICENSE"]` in place of the table form and the `License :: OSI Approved`
   classifier, with the setuptools floor raised to the version that supports them.
2. **Given** a clean checkout, **when** `python -m build` runs, **then** it prints neither of the
   two licence warnings, and the built wheel's `METADATA` shows `License-Expression: MIT`.
3. **Given** the change, **when** the `package` CI job runs, **then** the built wheel still installs
   and runs.

## Dev agent record

- **Floor:** `setuptools>=77`. The deprecation warning names 77.0.0 as the release that accepts both
  fields; 77.0.0 is not on PyPI, so the lowest build `>=77` resolves to is 77.0.1. A Python 3.9 build
  with setuptools 76.1.0 rejects the string form (`project.license` must be valid exactly by one
  definition), and one with 77.0.1 builds clean.
- **Build:** `python -m build` with build 1.6.1 (setuptools 84.0.0 in isolation) prints neither
  licence warning. The wheel `METADATA` and the sdist `PKG-INFO` read `Metadata-Version: 2.4`,
  `License-Expression: MIT` and `License-File: LICENSE`; the wheel carries
  `dist-info/licenses/LICENSE`.
- **Install:** the wheel, installed into a fresh virtual environment outside the checkout, runs
  `ruleprobe detectors` and `ruleprobe corpus --no-config --floor 0.9` with exit 0, as the
  `package` job does. The job's own run on the pull request is still to be confirmed.
- **Tests:** no unit test added; the change is build metadata, and the `package` job and the
  `METADATA` inspection are the checks this story names.

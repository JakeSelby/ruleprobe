## Goal

Move the changelog entry for the reference site's `Documentation` URL from `## 0.2.0` to
`## Unreleased`. The entry, written for #67, landed with #108 one commit after v0.2.0 was tagged,
but it went under the already-released 0.2.0 section: v0.2.0 (tag commit `ca93e24`) contains
neither the entry nor the URL. As it stands the changelog claims 0.2.0 ships a metadata link that the
0.2.0 wheel and sdist do not carry. Moving the entry makes the 0.2.0 section describe the tag and
lets the next release claim the URL. Nothing in the package changes.

## Acceptance criteria

1. **Given** `CHANGELOG.md`, **when** a reader looks under `## Unreleased`, **then** a `### Added`
   subsection holds the reference-site entry, word for word as it stood under 0.2.0, linking #67.
2. **Given** the `## 0.2.0 (2026-09-24)` section, **when** it is compared with `main` before this
   change, **then** the only difference is the removal of that three-line entry, and every other
   line is byte-identical.
3. **Given** `git show ca93e24:CHANGELOG.md` and `git show ca93e24:pyproject.toml`, **when** they
   are searched for `ruleprobe.jakeselby.com`, **then** neither holds it, which confirms the entry
   does not belong to 0.2.0.
4. **Given** the `## Gate` block in `AGENTS.md`, **when** it runs on this branch, **then** it passes
   with the expected clean-tree output, and `audit --delivery 117` reports 0 findings.

## Tasks

- [x] Confirm the v0.2.0 tag lacks the entry and the URL (AC: 3)

- [x] Add `### Added` under `## Unreleased` with the entry, word for word (AC: 1)
- [x] Check with `git diff` that the move is the only change to `CHANGELOG.md` (AC: 1, 2)
- [x] Run the `## Gate` block and `audit --delivery 117` (AC: 4)

## Design

- **Decision:** move the entry rather than reword it. The text is still accurate for the next
  release, and a word-for-word move keeps the diff reviewable as a pure relocation.
- **Alternative rejected:** leave the entry under 0.2.0. The changelog would then describe metadata
  the published 0.2.0 artifacts do not carry.
- **Alternative rejected:** amend or re-cut v0.2.0 to include the URL. A release is a tag and is
  never rewritten; the URL ships with the next release instead.
- **No unit test:** the change is changelog prose. No code reads the entry, and the release
  preflight already checks that the version and changelog agree.

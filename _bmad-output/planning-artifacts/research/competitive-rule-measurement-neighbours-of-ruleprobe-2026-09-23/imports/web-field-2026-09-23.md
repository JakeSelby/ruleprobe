# Web field map: tools measuring coding-agent behaviour from transcripts (2026-09-23)

Scope: neighbours of ruleprobe. 19 web searches, ~9 page fetches. Star counts and dates are as the fetched page reported them; "n/v" = not visible on the fetched page. Blog-post claims are secondary and marked.

## Verdict
Yes, rule compliance from transcripts is now a populated niche: at least two tools (claude-md-doctor, RuleReceipt) replay CLAUDE.md/AGENTS.md rules against Claude Code JSONL and report per-rule verdicts, mixing deterministic checks with an optional LLM judge. Neither was shown to read Codex rollouts. No observability platform ships a rule-compliance metric.

## 1. Direct competitors: rule compliance from transcripts

**claude-md-doctor** - https://github.com/agent-clinic/claude-md-doctor
- Reads CLAUDE.md/AGENTS.md, Claude Code transcripts in ~/.claude/projects, repo tree, git history.
- Reports: size vitals, dead references, drifted claims, and a per-rule backtest (followed / ignored / never used) with matched excerpts and session-timeline strips. Classifies rules into enforcement tiers hook / linter / test / judge; LLM audit verdicts carry a stated ~70% reliability ceiling.
- Local only ("nothing leaves your machine"); Python 3.9+, standard library only (per README). MIT. 38 stars. Last commit 2026-08-30 (README FAQ compares itself to Claude Code /insights and claude-md-improver). Codex support not shown.
- Closest match to ruleprobe in every dimension: stdlib Python, local, per-rule, transcript-based.

**RuleReceipt** - https://github.com/rulereceipt/rulereceipt ; blog https://dev.to/rulereceipt/i-measured-whether-claude-code-actually-follows-my-claudemd-25ao
- Reads Claude Code session JSONL plus CLAUDE.md/AGENTS.md. Claude Code only per the repo.
- Deterministic checks over git commands, file edits and file ops ("never commit to main", "never touch .env"); judgment rules go to an optional `--llm` call with the user's key, else reported UNCLEAR. Quotes evidence per verdict. Author claims a 2.9% false-accusation rate (blog, unverified).
- Local; `rulereceipt check` makes no network calls. TypeScript, npm (`npx rulereceipt`). Licence: source-available with restrictions (LICENSE + NOTICE.md), not OSI. 2 stars, ~240 commits, corpus data dated 2026-08-30. Same author also published a parse of 559 public CLAUDE.md files (https://dev.to/rulereceipt/i-parsed-559-public-claudemd-files-most-of-whats-in-them-isnt-rules-3flo).

**Agent MD Compliance Tester / skill-comply** (Claude Code skills) - https://mcpmarket.com/tools/skills/agent-md-compliance-tester , https://mcpmarket.com/tools/skills/automated-compliance-auditor
- Search-snippet level only: generates test scenarios from CLAUDE.md and scores compliance with an LLM. Prospective test generation, not transcript replay. Not fetched; licence n/v.

**Blog: "Your CLAUDE.md Rules Achieve 0% Compliance"** - https://dev.to/james-coombs/your-claudemd-rules-achieve-0-compliance-heres-the-data-kk3
- Secondary; claims rules get ~0% compliance for anything the agent would not do anyway. Not fetched.

## 2. Transcript and session analyzers (spend, tools, browsing; no rule compliance)

- **ccusage** - https://github.com/ccusage/ccusage (also ryoppippi/ccusage). Reads local JSONL for Claude Code, Codex, OpenCode, Gemini CLI, Copilot CLI, Amp and ~12 more. Reports tokens and estimated cost by day/week/month/session. Local. MIT (per a downstream repo's notice). Stars n/v; clearly the category leader.
- **cc-analyzer** - https://github.com/yorch/cc-analyzer. Read-only Claude Code analyzer: tokens, cost, tools, skills, models, per-turn; SQLite index, TUI, local web app. Bun/TS.
- **claude-session-analyzer** - https://github.com/yonk-labs/claude-session-analyzer. Python; per-session and per-skill token/cost/time, Textual TUI. Local.
- **ccdiag** - https://github.com/kolkov/ccdiag. Go; session analysis and recovery, orphaned tool calls, stuck tools.
- **claude-code-analytics** - https://github.com/sujankapadia/claude-code-analytics. Capture, search, KPI dashboard, heatmaps.
- **claude-code-transcripts** (Simon Willison) - https://github.com/simonw/claude-code-transcripts; **claude-code-log** - https://github.com/daaain/claude-code-log. Render JSONL to HTML/Markdown. Viewers, no metrics.
- **claude-code-trace** - https://github.com/delexw/claude-code-trace; **codex-trace** - https://github.com/Victarry/codex-trace. Viewers with tool calls, tokens, live tail.
- **Codex-specific**: codex-usage-analyzer (Rust; tokens, cost, latency, context composition) https://github.com/daguix/codex-usage-analyzer ; codex_usage_report (Go; cooldown estimates) https://github.com/rubens-amaral/codex_usage_report ; codex-logs https://github.com/wondercoms/codex-logs.
- **Cross-agent browsers**: Agent Sessions (macOS, Codex/Claude/OpenCode/Cursor/Copilot CLI, no telemetry) https://github.com/jazzyalex/agent-sessions ; coding_agent_session_search / CASS (11+ providers, search TUI) https://github.com/Dicklesworthstone/coding_agent_session_search ; agent-cli-session (local web app, Claude/Codex/Gemini/opencode/cursor-agent) https://github.com/POSTTTT/agent-cli-session.
- **ctxlint `--session`** (see section 3) reads the 5 latest Claude Code transcripts but only for loops and repeated commands.
- Licences and stars for most of this group were not fetched. None reports rule compliance.

## 3. Rule and instruction-file tooling (static; none measures behaviour)

- **ctxlint** - https://github.com/YawLabs/ctxlint (npm @yawlabs/ctxlint; a separate ctxlint/Ctxlint org also exists). MIT, 9 stars. 19 context-file rules (broken paths, wrong build commands, staleness, token budget, redundancy, cross-file contradictions) and 43 MCP-config rules. Explicitly does not claim to measure behavioural effect.
- **agnix** - https://github.com/agent-sh/agnix. MIT OR Apache-2.0, 421 stars. Linter + LSP for CLAUDE.md, AGENTS.md, SKILL.md, hooks, MCP, Cursor/Copilot/Cline/Kiro/Gemini formats; "456 rules"; autofix. Does not read transcripts.
- **AgentLinter** - https://agentlinter.com/. Hosted CLAUDE.md/skills linter. Not fetched.
- **cclint** - https://github.com/carlrannaberg/cclint. Claude Code config linter. Not fetched.
- **rulesync** - https://github.com/dyoshikawa/rulesync. Converts/syncs rules across Cursor, Copilot, Claude Code etc. **ai-rules-sync** - https://github.com/PanisHandsome/ai-rules-sync. Zero-dependency converter across AGENTS.md, CLAUDE.md, .cursorrules, Copilot, Windsurf, Cline, Aider, Gemini.
- Blog: "a linter that proves 74% of your AGENTS.md is wasting your agent's time" https://dev.to/vamshidhar_reddy_392c2302/i-built-a-linter-that-proves-74-of-your-agentsmd-is-wasting-your-ai-agents-time-46an - static "inferable content" claim, not behavioural.
- None of the static tools claims to measure whether a rule changed behaviour. Only the section-1 tools do.

## 4. Evaluation and observability platforms (absorption risk)

- **Anthropic, Claude Code /insights** - built-in command; reads ~/.claude transcripts for the last 30 days, emits an HTML report with friction analysis and *suggested* CLAUDE.md rules from repeated instructions (https://blog.vincentqiao.com/en/posts/claude-code-insights/, https://www.natemeyvis.com/claude-codes-insights/; secondary). It proposes rules; no source found saying it scores compliance with existing ones. This is the most direct first-party absorption path.
- **Anthropic OTel export** - https://code.claude.com/docs/en/monitoring-usage. Opt-in metrics (tokens, cost, sessions, lines) and events (tool decisions, errors, prompt.id). No instruction-adherence signal.
- **Anthropic Analytics dashboard / Analytics Admin API** - https://code.claude.com/docs/en/analytics , https://platform.claude.com/docs/en/manage-claude/claude-code-analytics-api. Daily per-user sessions, lines accepted, commits, PRs, Edit/Write accept rates. No compliance. A Compliance API also exists (https://platform.claude.com/docs/en/manage-claude/compliance-api); that is audit/data-governance, not rule adherence.
- **Langfuse** - https://langfuse.com/integrations/developer-tools/claude-code , https://langfuse.com/resources/engineering/coding-agent-tracing. Stop-hook reads transcript each turn; supports Claude Code, Codex, Copilot (OTel), Cursor, Kiro, OpenCode, Augment. Open source, self-hostable. Page states the loaded CLAUDE.md/skills context "is not part of what the hooks can read today". No rule evaluator shipped; generic LLM-judge evals could be pointed at it.
- **LangSmith** - https://docs.langchain.com/langsmith/trace-claude-code , https://github.com/langchain-ai/langsmith-claude-code-plugins. Traces Claude Code, Codex, Cursor, Copilot Chat, OpenCode; blog "debug coding agents with LangSmith traces". Hosted. No instruction-compliance metric found.
- **Braintrust, Arize Phoenix, Helicone, Latitude** - vendor comparison pages only (e.g. https://www.braintrust.dev/articles/agent-observability-complete-guide-2026, https://arize.com/resources/llm-and-agent-evaluation-platforms/). Generic custom scorers/LLM judges; no search surfaced an "instruction adherence" or CLAUDE.md-rule evaluator for coding sessions. Latitude markets an MCP loop from detected issue to fix PR.
- Summary: all the big platforms now ingest coding-agent transcripts, so the data path exists; none has a packaged rule-compliance metric as of this search.

## 5. Academic and blog work (2025-2026)

- **A First Look at Coding Agents' Compliance with AI Contribution Rules** (Yang, He, Zhou, PKU, 2026-07-29) https://arxiv.org/abs/2607.26819. Hybrid: mechanical checks for objective signals, LLM judge with human-calibrated rubrics for refusals/escalations. Agents opened policy files in 3.5% of runs; Refuse 0%, Handoff 0% unaided; Disclose 17-40% rising to 77-97% with feedback.
- **Instruction Adherence in Coding Agent Configuration Files: a factorial study** (McMillan, 2026-05-11) https://arxiv.org/abs/2605.10039. Deterministic checks over 1,650 Claude Code CLI sessions / 16,050 function observations. File size, placement, design, conflicts: no detectable effect after correction; compliance odds fall ~5.6% per additional function in-session (OR 0.944). Strongest evidence for deterministic transcript measurement.
- **OctoBench** (2026-01-15) https://arxiv.org/abs/2601.10343. Scaffold-aware instruction following; 217 tasks, 7,098 objective checklist items over captured trajectories; gap between task-solving and compliance.
- **HANDBOOK.md** (2026-07) https://arxiv.org/abs/2607.25398. 65 long-horizon handbook-following tasks; best model 36.2% strict pass.
- **The Compliance Gap** (Shin, 2026-05-03) https://arxiv.org/abs/2605.01771. 2,031 sessions, six models, 0% process-instruction compliance under default framing; argues the gap is undetectable from text alone, i.e. must be measured from behaviour.
- **The Stability Trap** https://arxiv.org/html/2601.11783. LLM adherence auditors agree on verdicts while citing hallucinated evidence; recommends hybrid: deterministic code for verifiable logic, LLM only for semantics.
- **LLM-as-a-Judge Is Not an Oracle** https://arxiv.org/abs/2609.02246. Judge demoted to advisor behind a deterministic verification layer; eleven failure modes.
- **Evaluating AGENTS.md** (Gloaguen et al., ETH, 2026-02) https://arxiv.org/abs/2602.11988: context files do not improve task success and raise cost >20%. Counterpoints: Lulla et al. (efficiency gains), **Do Context Files Help Coding Agents?** https://arxiv.org/html/2607.27250, **Probe-and-Refine Tuning of Repository Guidance** https://arxiv.org/pdf/2606.20512. These measure outcome, not rule adherence.
- MAC-Bench https://arxiv.org/html/2606.07805v1 translates regulations into executable atomic rules checked over tool-use trajectories (non-coding, but the same deterministic-oracle pattern).

## Gaps and caveats
- Codex-rollout rule compliance: no tool found. Cursor/Gemini/Copilot rule compliance: none found.
- Stars/licences for most viewers and ccusage not verified; claude-md-doctor's stdlib-only claim is from its README, not verified by code.
- /insights capability is from secondary blogs; Anthropic's own docs page for it not fetched.
- Braintrust/Arize/Helicone docs not fetched directly; conclusion "no packaged metric" is absence-of-evidence.
